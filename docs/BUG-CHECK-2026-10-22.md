# Bug check and drawing follow-up — 2026-10-22

Scope: the user requested checking other parts of DeepSeek Lab and adding interpreted commands for drawing.

## Fixed

- **Follow-up draft erased by delayed send:** Website Chat used to clear the editor unconditionally when a send acknowledgement arrived. It now clears only the text actually submitted and preserves a follow-up typed during the request.
- **Cross-task draft timer:** API task switching now stops the old editor's draft timer and disables editing until the selected draft is loaded, preventing the old draft from being saved under the newly selected task. Website draft saving also waits for loading to finish.
- **Delayed artifact save replacing another selection:** Save callbacks are now bound to the artifact ID and submitted revision. Switching artifacts ignores a stale callback, and edits made after submitting a save remain intact.
- **Long transcript tail inaccessible:** The inline transcript's bounded-height browser now enables internal overflow when necessary. The outer conversation scroll follows new content only when appropriate instead of always jumping from the user's reading position.
- **Background service lifetime:** On Linux with a user systemd manager, service startup now uses a transient unit named for the state directory. This outlives the launching shell/window and is not enabled at boot. Only selected display/session environment variables and explicit source/state paths are forwarded; API-key environment variables are not forwarded into the unit command. Restart now also handles the old unit being collected while the replacement is starting. Other platforms keep the detached-process fallback. Source changes and an idle restart retain the durable records and saved website login.
- **Drawing reply format mismatch:** The live model returned a valid command-only drawing without fences. The interpreter now accepts that exact bounded format as well as explicit fenced drawings. The existing saved reply can be reprocessed; no model retry is needed.
- **Drawing PNG background and edges:** Native SVG rendering did not fill a percentage-sized background consistently. Drawing backgrounds now use explicit dimensions; PNG export enables geometry/text antialiasing. Pixel checks verify a fully opaque background at the far edge.

## Drawing capability

See [drawing command reference](DRAWING-COMMANDS.md). Chat gets interpreted drawing programs; API Code gets a `draw_visual` tool. Primitives are editable/exportable artifacts. Inference instructions explain the output interpreter so DeepSeek should not claim that plain text prevents it from drawing. External websites do not gain shell/tool access through this format.
